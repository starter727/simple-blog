# Python 基础教程

这是一篇 Python 入门文章。

## 第一章：变量和数据类型

```python
# 变量定义
name = "Alice"
age = 25
height = 1.65

# 数据类型
print(type(name))   # <class 'str'>
print(type(age))    # <class 'int'>
print(type(height)) # <class 'float'>
```

## 第二章：控制流

```python
# 条件语句
if age >= 18:
    print("成年人")
else:
    print("未成年人")

# 循环
for i in range(5):
    print(i)
```

## 总结

Python 是一门简单易学的编程语言。
